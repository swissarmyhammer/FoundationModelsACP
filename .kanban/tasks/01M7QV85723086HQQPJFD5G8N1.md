title: Generate the session/fork types and SessionCapabilities.fork through the unstable overlay

D205 (TestudoApp/features/decisions.md). Brief: ../.briefs/fork/acp-brief.md, item 1 and item 4.

The overlay can add definitions and union variants. It cannot add a member to a stable definition, and it cannot route an unstable method with types. Add two fields to `GeneratorConfig.UnstableOverlay`:
- `members`: a stable definition name and the property names that the overlay copies from the unstable definition of the same name.
- `methods`: unstable wire methods that route as typed methods (the overlay copies their definitions).

Then add `ForkSessionRequest`, `ForkSessionResponse`, `SessionForkCapabilities`, the member `SessionCapabilities.fork` and the method `session/fork` to `GeneratorConfig.acpV2`, and run the generator.
