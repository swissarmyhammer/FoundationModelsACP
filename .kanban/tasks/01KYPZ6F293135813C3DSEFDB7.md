M9 (^p68s7v7) deferred third-party interop testing because no real v2 agent or client exists yet to round-trip against: v2 is a draft schema (schema-v2.0.0-alpha.2), and both intended consumers (FoundationModelsACPAgent, FoundationModelsACPClient) are themselves unimplemented. See Tests/FoundationModelsACPTests/ThirdPartyInterop.swift for the full reasoning — in short, a mock "interop" test against our own Agent/Client would only rename a unit test and cannot falsify "we implement v2" vs "we implement our reading of v2", which is the entire point of this acceptance criterion.

Pick this up once any of the following exists:
- A reference v2 agent or client implementation from the ACP project itself.
- An independent third-party v2 SDK.
- FoundationModelsACPAgent or FoundationModelsACPClient reaches a state where it can be driven against this package's other role, or against an external peer.

Acceptance: a live round trip (initialize through at least one full prompt turn) against a real, independently-implemented v2 peer, run over stdio (SubprocessTransport) or a genuine separate process — not InMemoryTransport, since the whole point is crossing a real process/implementation boundary. Record any divergence from this package's reading of the draft schema as its own follow-up.
